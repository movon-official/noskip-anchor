# ノースキップ 競艇予想AI — 予想の事前固定記録（anchor）

このリポジトリは、「ノースキップ 競艇予想AI」が毎朝生成する当日全レースの予想（各艇の勝率と券種別の買い目）を、レースの締切前に固定した記録です。予想そのものを配信する場所ではありません。

## 仕組み

1. 毎朝、当日の全レース分の予想を1つのJSONファイルにまとめ、そのSHA-256ハッシュ値を `anchor_YYYYMMDD.sha256` としてここへpushします（その日の最も早いレースの締切前）。
2. 同じJSONファイルを OpenTimestamps でも刻印します（`.ots`）。
3. 全レース終了後、JSONの原文を `revealed/anchor_YYYYMMDD.json` に公開します。

朝に固定したハッシュ値と、夜に公開した原文から計算したハッシュ値が一致すれば、「締切前に存在した予想が、後から差し替えられていない」ことを誰でも確認できます。外れた予想も消さず、選ばず、後から直しません。

## 確認方法

```
sha256sum revealed/anchor_20260826.json
cat anchor_20260826.sha256
```

2つの値が一致すれば、朝に固定した予想と夜に公開した原文は同一です。
固定された時刻は、このリポジトリのpush履歴と `.ots` ファイル（`ots verify revealed/anchor_20260826.json.ots`）で確認できます。
commitの日時は後から書き換え可能なため、根拠にはpush時刻（GitHub Events API の `pushed_at`）と OpenTimestamps（Bitcoinブロックチェーン）を用います。

## JSONの内容

- `date` / `spec` / `provenance`（予想モデル・確率変換パラメータ・買い目生成コードの版をハッシュで記録）
- `races[レースID]`: 場・レース番号・締切時刻・予想生成時刻・各艇の勝率 `p_win`・3モード×7券種の買い目 `plans`

## 注意

- 本記録は「予想がいつ存在し、その後変わっていないこと」を示すものです。的中を約束するものではありません。
- 舟券の販売・購入代行は行っていません。20歳未満の方は舟券を購入できません。
